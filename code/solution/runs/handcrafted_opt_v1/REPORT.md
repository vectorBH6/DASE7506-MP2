扩大 L2 后，0.03 的 NLL 从 0.46345 降到 0.44832，但准确率从 82.1192% 降到 81.9300%；概率损失改善没有转化为本任务的选答准确率提升，因此仍选 0.01。
手工块倍率 0.3 和 3 的 OOF 准确率均低于 1；本轮未发现分块惩罚带来的增益。
两项交互特征的最佳 OOF 为 81.8827%，低于原 82.1192%；validation 纠正/改错各 1 题，总分持平。
所有搜索均收敛，且各阶段折号和标签与原实验一致。扩大 L2 与分块搜索最终导出的权重、标准化数组逐位等于原 6 维模型。
最终保留原 6 维模型是 test 之前的验证集/OOF 决策；test 逐题预测与原归档完全一致。
